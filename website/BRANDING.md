# Zetaris branding

Use the user-supplied **Zetaris Brand Guidelines 2026.pdf** as the branding reference for this site. The original supplied file is `/Users/bevanlewis/Downloads/branding/Zetaris Brand Guidelines 2026.pdf`; its accompanying logo exports are in the sibling `SVG/` and `SVG 2/` directories. These local paths record provenance and are not build dependencies.

## Applied rules

- Indigo Pulse `#4052F2`, Deep `#2F3EC2`, Soft `#7C89F7`, Mist `#DBE0FD`, Tint `#F3F5FE`.
- Obsidian `#06070D`, Ink 2 `#15171F`, Ink 3 `#2A2D39`, Text 3 `#595E6E`, Border `#E7E7EE`, White `#FFFFFF`.
- Plus Jakarta Sans. Desktop H1: 48px, weight 800, -3% tracking. H2: 32px, weight 700, -2% tracking. Body: 16px with 1.55 line height. Smaller headings on mobile retain the hierarchy. Code uses a monospace font.
- 8px and 12px component radii, with spacing based on the guide's 4px scale.
- Plain, precise claims and Australian spelling. The documentation retains its recorded evidence and limitations.
- Use the supplied logo variants without recolouring, stretching, rotating, cropping clear space or adding visual effects. The SVG exports contain their own shading; preserve that artwork unchanged.
