# Prepare your demo

Use this template to record a demo someone else can follow. Check the [official event page](https://hackathon.genai.works/event/open-agent-hackathon-2026) for current deadlines and required deliverables.

Copy this into your project notes and fill in the sections that apply.

## What did you build?

- What question does it answer?
- Show a result table, chart or working app.
- What is missing or still needs checking?

## What data did you use?

| Source and version | Your tables or views | What each row means | Dates covered and limitations |
|---|---|---|---|
| Add the source link and required attribution | Use your team's names | Describe one row | Note missing data or uncertain matches |

## How can someone run it?

1. List the access and tools they need. Do not include credentials.
2. Save the setup SQL in execution order. Note any existing objects to reuse.
3. Save the query and a small example of its output.
4. Explain how to start your app, if you built one.
5. Record when you ran it and the source version. Note which connections, rows, joins and app steps you checked.

If you used sample data to test the interface, say so. Ask a teammate to try it with real data.

## Before you finish

List the objects your team created. Remove only project objects you intend to delete, and retain any data you still need. See [cleanup](troubleshooting.md#cleanup).
