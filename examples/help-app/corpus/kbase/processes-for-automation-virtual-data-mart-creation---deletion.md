# Processes for Automation: Virtual Data Mart creation / deletion

## This article explains how to create and delete Virtual Data Marts (VDMs) in Zetaris.

**Steps to Create a Virtual Data Mart**

1.  Login to Zetaris
    
2.  Go to the Virtual Data Mart tab
    

 ![VDMImage1](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage1.png)

  

![](blob:https://zetaris.atlassian.net/51c632e6-5517-446f-8a95-02c9b57bf0cc#media-blob-url=true&id=eb36f23a-141b-442d-8652-8b4064a7db33&collection=contentId-2621505634&contextId=2621505634&height=96&width=977&alt=)3.   On the left pane, Click on the plus button (+) next to Data Marts.

  

![VDMImage2](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage2.png)  

4.   A pop-up will appear. Fill in the details and click the "Create" button

![VDMImage3](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage3.png)  

![](blob:https://zetaris.atlassian.net/4645ec01-1dbf-4333-a47f-4206a112ab49#media-blob-url=true&id=3365855f-c90b-40fc-b312-42022a4a3737&collection=contentId-2621505634&contextId=2621505634&height=263&width=599&alt=)5.   Once the create button is clicked, the middle pane will be available for dragging and dropping data sources needed for your Data Mart. If there are links between tables it also possible to join them. (This is not a mandatory step.)

![VDMImage4](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage4.png)

  

6.   Once all the tables/data sources are dragged and dropped in the middle pane click on "Save changes."

7.   This will save your data mart for future use.

**Steps to Delete a Virtual Data Mart**

1.  Login to Zetaris
    
2.  Go to the Virtual Data Mart tab
    

 ![VDMImage5](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage5.png)

![](blob:https://zetaris.atlassian.net/0bd95a93-726b-4ea2-b2f5-c5323e3cd680#media-blob-url=true&id=eb36f23a-141b-442d-8652-8b4064a7db33&collection=contentId-2621505634&contextId=2621505634&height=96&width=977&alt=)

 3.   On the left pane, under Data Marts, all the available Data Marts are listed.

  

![VDMImage6](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage6.png) 

4.   Click on the bin to delete a particular Data Mart.

5.   The Data Mart will be deleted.

**Steps to Update a Virtual Data Mart**

1.  Login to Zetaris
    
2.  Go to the Virtual Data Mart tab.
    

 ![VDMImage7](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage7.png)

![](blob:https://zetaris.atlassian.net/5d0d3ab2-f207-4e68-8024-c9ba747dfe0e#media-blob-url=true&id=eb36f23a-141b-442d-8652-8b4064a7db33&collection=contentId-2621505634&contextId=2621505634&height=96&width=977&alt=)

3.   On the left pane, under Data Marts, all the available Data Marts are listed.

  

![VDMImage8](https://kbase.zetaris.com/hs-fs/hubfs/VDMImage8.png) 

4.   Click on the Data Mart which needs to be updated.

5.   After clicking, the middle pane will show the data sources in that data mart.

6.   Simply drag and drop more tables as required. The "Clear model" button can also be used to clear the model completely so you can start afresh.
