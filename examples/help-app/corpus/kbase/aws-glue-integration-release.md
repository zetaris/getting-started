# AWS Glue Metastore Integration

## Zetaris now supports connectivity to AWS Glue metastore

AWS Glue is a fully managed extract, transform, and load (ETL) service that can categorize , clean ,enrich and move data between various data stores. The AWS Glue Data Catalog provides a unified metadata repository across a variety of data sources and data formats, in the AWS eco system, and any application compatible with the Apache Hive metastore.   
  
The Zetaris Glue metastore connection now allows simultaneous access to cross account AWS Glue catalog by creating primary, secondary, tertiary connections.  
  
With the addition of access to the Hive metastore and Glue catalog, the possibility of cross platform joins has become more powerful, leading to faster insights across big data platforms.
