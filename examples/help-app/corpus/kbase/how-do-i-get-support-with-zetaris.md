# How do I get Support from Zetaris?

## Its easy and fast to access Zetaris SME's via our comprehensive Support Model

### Support Channels 

Zetaris provides the following channels to resolve any query you might have with Zetaris Software:

1.  Self Service Product Documentation via  [Zetaris Knowledge base](https://kbase.zetaris.com/knowledge/)
2.  Self Service Enhanced Product Documentation via [Zetaris Customer Portal](https://portal.zetaris.com/)
3.  Contact Zetaris Support via email using [<REDACTED>](mailto:<REDACTED>)
4.  Log a ticket via the [Zetaris Support Portal](https://kbase.zetaris.com/tickets-view)
5.  Book a meeting via [Zetaris Ask an Expert](https://calendly.com/d/x4w-yk4-q8b/customer-success-touchpoint)
6.  Direct Chat via Slack channel [#Zetaris-Ask-Help](https://app.slack.com/huddle/T034UGRLR/C04NSTJTB8E)

### Product Type Support 

Whilst Zetaris offers a number of easily accessible support channels for both trial and paying customers, the Service Level Agreements (SLAs) or commercially committed response time is dependent on the Product Type Purchases.
