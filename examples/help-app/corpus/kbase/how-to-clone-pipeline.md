# How to clone Pipeline

1.  Login to zetaris
    
2.  go to pipeline tab.
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-29-56-0044-AM.png)
    
3.  find the pipeline that needs a clone
    
4.  click on three dots next to the pipeline. Then click on clone.
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-30-11-5699-AM.png)
    
5.  this will open an pop up
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-30-28-3607-AM.png)
    
6.  select the container where new pipeline needs to be cloned and also give the new pipeline name.
    
7.  This will clone your pipeline.
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-30-43-1757-AM.png)
