# Product Version 2.3.4.0 (4th Dec 2023)

### Feature Enhancements

-   Zetaris users can now effortlessly create a data catalog and efficiently classify the data fields on a file source, such as CSV and Parquet.
-   Increase your [canvas space](https://kbase.zetaris.com/knowledge/zetaris-canvas-management) on the Zetaris Virtual Data Marts and Zetaris Virtual Data Pipelines and have more room to work efficiently.
-   Take advantage of the [API token generator](https://kbase.zetaris.com/knowledge/time-managed-keys-for-the-zetaris-api) to easily obtain permanent or temporary tokens for seamless connectivity to the Zetaris API.

#### Minor Bug Fixes:

-   Improvement made to "secrets" masking for the AWS and Azure data lakehouse wizard.
-   Improved prompting on the SQL Server connection wizard to assist users in entering database names and schema names more effectively.
-   The file write option in the Virtual Data Pipeline sink now supports default no-partition for small-sized data outputs.
