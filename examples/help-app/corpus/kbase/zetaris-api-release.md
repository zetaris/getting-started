# Zetaris Lightning API

## Introducing Zetaris Lightning RESTfull API (Data as a Service)

APIs are useful for more than accessing information for data-driven decision-making. It can be used to build programs that run searches on the data that Zetaris is hosting and transform that information into a different, usable format. Rather than building a web-based information platform from scratch, companies can use the Zetaris API to incorporate all of the virtualization technology that Zetaris provides.

The usage of an API is meant to improve information security and the ease with which you can access the data you need to make well-informed business decisions. 

The [Zetaris API documentation](https://github.com/zetaris/zetaris-public) within the platform provides users with all relevant information.
