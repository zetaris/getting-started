# Product Version 2.3.1.0 (13th June 2023)

Feature Enhancements

-   [Apache Iceberg Integration](https://kbase.zetaris.com/knowledge/data-migration-using-apache-iceberg-in-zetaris) Phase 2 - with VDP (Virtual Data Pipeline) integration
    
-   Improvement to Streaming Options (Improve Config Options & Automate Schema Creation)
    

### Bug Fixes

-   Fixed the issue where Virtual data pipelines were not being  saved into datamarts
-   Special character handling for Glue databases have been fixed
-   Fix applied to VDP validation wherein addition of a Simple DQ step could override virtual column validations.
