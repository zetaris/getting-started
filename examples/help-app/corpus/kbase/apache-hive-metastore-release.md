# Apache Hive Metastore Integration

## Zetaris now supports connectivity to Apache HIVE Metastore

Apache Hive is an open source data warehousing software that allows users to read, write, and carry out transformations on large datasets residing in distributed systems. A Hive Metastore is the central repository of metadata for a Hive cluster. It stores metadata for data structures such as databases, tables, and partitions in a relational database.

  
Zetaris now opens up access to the customer's Hive metastore allowing users to gain insights from the massive datasets that have incrementally contributed to the Hive metastore.
