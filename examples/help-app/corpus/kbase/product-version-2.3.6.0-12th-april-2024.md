# Product Version 2.3.6.0 (12th April 2024)

### Feature Enhancements

-   Zetaris users can now effortlessly create data science insights using integrated web based  [Zeppelin notebook](https://kbase.zetaris.com/knowledge/zeppelin-notebook-in-zetaris)
-   Group the Zetaris views into logical/functional categories by using the containers
-   Zetaris supports the S3 endpoint for object store.

#### Minor Bug Fixes:

-   Improvement made to "caching" operations for Virtual data base.
