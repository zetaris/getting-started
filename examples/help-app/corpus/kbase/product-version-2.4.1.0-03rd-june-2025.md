# Product Version 2.4.1.0 (03rd June 2025)

### Major features

-   User Interface changes
    
    \- Enhanced user interface
    
    \- Consolidated submenus
    
    \- Upgraded SQL workspace
    
    \- Virtual datamart zoom functionality
    
    \- Improved error messaging
    
-   Lake house (namespace, table , snapshots management)
    
-   Compute engines (Query Director) - Spark and Presto - [How to create spark and presto engines](https://kbase.zetaris.com/knowledge/how-to-create-spark-and-presto-engines)
    
-   HADB support -  [How to connect to HADB](https://kbase.zetaris.com/knowledge/how-to-connect-to-hadb)
    
-   Schema store view - Column based control -  [How to apply CBAC on View](https://kbase.zetaris.com/knowledge/how-to-apply-cbac-on-view)
    
-   AWS session token support -  [How to connect AWS S3 with access token](https://kbase.zetaris.com/knowledge/how-to-connect-aws-s3-with-access-token)
    
-   Virtual partition management -   [How to create Virtual Partition](https://kbase.zetaris.com/knowledge/how-to-create-virtual-partition)
    
-   Pipeline clone -   [How to clone Pipeline](https://kbase.zetaris.com/knowledge/how-to-clone-pipeline)
    
-   Performance improvements
    
    -   Resolved an issue where opening datasources with extensive table volumes resulted in significant performance degradation
-   Spark 3.5.3 upgrade
    

#### Major Bug Fixes

-   Glue fixes
    
    -   Glue integration issue with Delta Lake resolved.
-   Teradata fixes
    
    -   Resolved issue preventing creation of Teradata datasource using the GUI.
