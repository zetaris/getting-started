# User Management

## How to create and manage users into roles

[Local User Management](#local-user-management)

[Local Role Management](#local-role-management)

Zetaris' users can be authenticated and created locally, or Zetaris can be integrated with an existing authentication provider through LDAP, where we are able to synchronise on-boarding of new users. 

### Local User Management

Follow the steps below to create and delete local users

#### **Steps to create user:**

1.  Login to Zetaris
    
2.  Click on user management tab
    

![Image1](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image1.png)

3.   Click on the plus button next to users. Pop-up will appear  

![Image2](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image2.png)

![](blob:https://zetaris.atlassian.net/ec8bb3fa-c3af-4e53-a3fd-43bf0ace724a#media-blob-url=true&id=edea2216-27ec-4fb1-afb4-eb57e57cac47&collection=contentId-2618950117&contextId=2618950117&height=368&width=581&alt=)4.   Enter your details. Then click on Add 

![Image3](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image3.png)

The user will be created.

![Image4](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image4.png)  

#### **Steps to Delete user:**

1.  Login to Zetaris
    
2.  Click on user management tab
    

![Image5](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image5.png)  
  

![](blob:https://zetaris.atlassian.net/99dbd6ab-c541-46b5-8d79-d026fba42e09#media-blob-url=true&id=37ed9744-75f7-47b7-b7e1-4f8b0956b198&collection=contentId-2618950117&contextId=2618950117&height=156&width=965&alt=)3.   Click on bin button next to user that needs to be deleted. Pop-up will appear to confirm to delete user

![Image6](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image6.png)  

4.   Click on “Yes” and user will be deleted.

### Local Role Management

Follow the steps below to create and delete local users

#### **Steps to add Roles:**

1.  Login to Zetaris
    
2.  Click on user management tab
    

![Image7](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image7.png)

3.   Click on the plus button next to roles. Pop-up will appear

![Image8](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image8.png)  

4.   Enter details and the click on create a new role will be created

![Image9](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image9.png)  
  

**Steps to delete Roles:**

1.  Login to Zetaris
    
2.  Click on user management tab ![Image10](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image10.png)
    

3.   Click on bin button next to role that needs to be deleted. Pop-up will appear to confirm to delete role

![Image11](https://kbase.zetaris.com/hs-fs/hubfs/knowledge_base_images/processes-for-automation/Image11.png)   

4.   Click on “Yes” and role will be deleted
