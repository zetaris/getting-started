# Overview of connecting to Zetaris

As an end-user wanting to access the data assets that have been created inside Zetaris, there are a number of options available for connecting.

### Access via Zetaris

Anyone can login to the platform, though given what type of user you are (admin or end-user), what functions you can access and what data is available to you will be different.

As an end-user, you are able to make use of the **SQL Editor** and **Query Builder**, for doing ad-hoc analysis, or curating datasources of your own to use again.

### Other Methods

Zetaris is an agnostic query engine, that is not limited to where or who uses it. As such we offer complete compatibility via **JDBC**, **ODBC** and **REST API**.
