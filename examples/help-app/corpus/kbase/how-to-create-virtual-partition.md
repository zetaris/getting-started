# How to create virtual partition

1.  Login to zetaris.
    
2.  go to the datasource table where virtual partition is needed. Click on three dot next to it.
    
    ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-27-18-3047-AM.png) 
    
3.  click on “configure virtual partition”. pop will appear.
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-27-33-7935-AM.png)
    
4.  select the column on which you partition is needed. only the column which can be partitioned will be displayed in dropdown.
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-27-47-5183-AM.png)
    
5.  put the count of partition you want. also put upper bound and lower bound.
    
     ![](https://kbase.zetaris.com/hs-fs/hubfs/image-png-Sep-24-2025-02-28-03-5809-AM.png)
    
6.  then click on set partition. this will create the partition
