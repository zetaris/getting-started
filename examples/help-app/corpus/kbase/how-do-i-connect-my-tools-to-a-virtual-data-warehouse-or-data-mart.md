# How do I connect my tools to a Virtual Data Warehouse or Data Mart?

Connecting to a Virtual Data Warehouse or a Virtual Data Mart, can be made using an external client, through any of the three protocols,

-   [JDBC](https://kbase.zetaris.com/knowledge/connecting-to-zetaris#access-via-jdbc)
-   [ODBC](https://kbase.zetaris.com/knowledge/connecting-to-zetaris#access-via-odbc)
-   [REST API](https://kbase.zetaris.com/knowledge/connecting-to-zetaris#access-via-rest-api)

or internally, by the end-user simply logging into their Zetaris server
