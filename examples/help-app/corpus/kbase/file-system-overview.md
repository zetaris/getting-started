# File System Overview

**NDP File System** is where you store files in Zetaris. You can upload CSV, Excel, XML, JSON, Parquet, ORC, Avro and Delta files, and register them as file sources to query them.

You can upload other file types, such as PDFs, images and videos, for storage. These cannot be registered as a data source.

Open NDP File System

In the left navigation, select **NDP File System**. It opens in a new tab and shows the top-level folders under **Home**.

![](https://kbase.zetaris.com/hs-fs/hubfs/undefined-Oct-28-2026-06-32-08-0443-AM.png)

Each row shows the **Name**, **Size**, **Modified** date and an **Actions** menu. Select a folder name to open it. Use the path at the top (for example, **Home / file-store**) to go back up.

![](https://kbase.zetaris.com/hs-fs/hubfs/undefined-Oct-28-2026-06-32-08-2586-AM.png)

Upload Files

1.  Open the folder you want to upload to.
2.  Select the **Upload** icon at the top right.
3.  Drag files into the panel, or select **Browse files**.
4.  Open the folder where you want the new folder.
5.  Select the **New folder** icon at the top right.
6.  Enter the folder name and select the tick to create it.

Files are uploaded to the folder you are in. Select **×** to close the upload panel.

Create a Folder

The path the folder will be created at is shown under the name field.

Rename, Move or Delete

Select the actions menu (⋮) at the end of a file or folder row, then choose **Rename**, **Move** or **Delete**.

To delete several items at once, select their checkboxes and then the delete icon in the bar that appears above the list.
