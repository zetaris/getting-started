# Additional Access Management Pattern - SAML (OKTA) Integration

## Zetaris now supports Single Sign On via SAML/OKTA integration

Zetaris now supports Single Sign On using the SAML (Security Assertion Markup Language) standards. Using this feature, customers can now integrate the Identity provider of their choice like Okta or SAML on Azure to unify access control mechanisms across the enterprise. 

  
Enabling this feature allows the Zetaris UI to be integrated with any SAML service provider to enable a single sign on experience for Zetaris.
