# Multi-Tiers of User Access Control

## Zetaris now supports detailed user access control

There are multiple data teams in large enterprises with different roles and responsibilities when it comes to delivering end to end data products. This new feature will enable organisations to have a single platform to  maintain segregation of duties between these teams and reduce the risk of unauthorised changes to the platform.

This feature allows additional User Type based on personas which have less privileges than the “Admin” user but more privileges than the "BI consumer"  For example, this user type will be able to own and manage their own Virtual Data Marts and Data Pipelines but cannot modify connections to data sources.
